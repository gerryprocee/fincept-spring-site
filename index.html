Fincept Spring

A personal market-research application

Fincept Spring is a private, self-hosted web application for following markets, news, watchlists and an investment portfolio. It runs only on its owner's own computer (bound to 127.0.0.1) and is not offered as a service to other people.

Google Sheets

The owner can link their own Google account so the application can:

  • read a portfolio spreadsheet the owner explicitly links, and keep it in sync with the application;
  • write current prices into that spreadsheet;
  • create a spreadsheet with buy suggestions in the owner's own Google Drive.

The application only accesses spreadsheets the owner links or that the application created. See the privacy policy for how this data is handled.
