Privacy policy

Fincept Spring · effective 4 October 2026

Fincept Spring is a personal application that runs only on its owner's own computer. It is not a hosted service and has no other users. This policy explains what the application does with data from Google.

What the application accesses

With the owner's consent, the application uses the Google Sheets API with the scope https://www.googleapis.com/auth/spreadsheets. It reads and writes only the spreadsheets the owner explicitly links in the application, plus a spreadsheet the application creates for buy suggestions. It does not browse or search the owner's Google Drive and does not access email, contacts or any other Google data.

How the data is used

  • Portfolio positions (such as ISIN, quantity, average price, broker, strategy label, target weight and notes) are read from the linked spreadsheet and kept in sync with the application.
  • Current prices are written to the linked spreadsheet.
  • The data is used only to provide these features to the owner.

Where the data is stored

  • Portfolio data is stored in a local database on the owner's computer.
  • The Google refresh token is stored in the macOS Keychain on that computer. It is never stored in the database, written to log files or sent anywhere other than to Google.
  • No data is stored on servers operated for this application.

Sharing with third parties

Google user data is not sold, not used for advertising and not shared with anyone, with one exception that only happens at the owner's own request:

  • AI assistant (optional). When the owner asks the built-in AI assistant a question or requests buy suggestions, portfolio data, which may originate from the linked spreadsheet, can be sent to the Anthropic API to answer that request. This happens only when the owner initiates it, under the owner's own Anthropic API account and Anthropic's commercial terms.

Market prices are fetched from public market-data sources; no Google user data is sent to them.

Limited Use

Fincept Spring's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • The owner can unlink Google at any time on the application's Google page, which also revokes the token.
  • Access can also be removed in the Google Account under Security → Third-party apps with account access.
  • Deleting the application's local data directory removes all stored portfolio data.
